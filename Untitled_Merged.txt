SECTION 1

Always write 'write' in 'enable' mode to ensure that you saved your progress on devices!

1.1) Hostname and Interface Description config:

Inside Router:
en
conf t
hostname R1
interface gigabitethernet0/0
descripttion Sw1 (case sensitive)


Inside Switch:
en
conf t
hostname Sw1

For the router:
interface gigabitethernet0/1
description R1

For PC's(do similar for all interfaces):
interface fas0/1
description PC1



1.2) IP Planning:

network id: right side of subnet bit should all be 0's
broadcast id: right side of subnet bit should all be 1's
first usable id: network id + 1
last usable id: broadcast id - 1
total usable IPs: 32-subnet_num

now, click PCs one by one and assign the following:

Desktop>IP configuration> IPv4 address, subnet mask & default gateway.

For the Router:

if inside an interface(config-if) use the 'exit' command first.

then: 

interface gigabitEthernet0/0
ip address ip_address subnet_mask
no shutdown


For the Switch:

if inside an interface(config-if) use the 'exit' command first.

interface vlan 1
ip address ip_address subnet_mask
no shutdown
end


SECTION 2

2.1) STP PortFast config(for end users):

Open the Switch and do the following:

en
conf t 
then, there are 2 ways:
one by one:
interface fastEthernet 0/1 
spanning-tree portfast

or:

interface range fastEthernet 0/x-y
spanning-tree portfast


2.2) STP BPDU Guard config(for end users):

open the Swtich:

interface range fastEthernet 0/x-y
spanning-tree bpduguard enable



2.3) DHCP Snooping config:

open the Switch:

ip dhcp snooping vlan 1
interface gigabitEthernet0/1  (linked with the router)
ip dhcp snooping trust

you can check with:

show ip dhcp snooping


SECTION 3

3.1) SSH config on R1:

Open the Router:

for ssh config, we need both host name and domain name(we have hostname as previously assigned)

if hostname exists, just type:

ip domain name exam.com

then, write this exactly:

username admin password admin

continue:

crypto key generate rsa
1024
ip ssh version 2
line vty 0 15
transport input ssh
login local

For accessing to the router with PC's, we first need to type the following on the router's CLI:

enable password admin



3.2) SSH config on Sw1:

ip domain name exam.com
username admin password admin (maybe there will be secret instead of password)
crypto key generate rsa
1024
ip ssh version 2
line vty 0 15
transport input ssh
login local
enable password admin

SECTION 4

4.1) ACL config on R1:

Open R1:

ip access-list extended 100
permit tcp host ip_address_of_pc1 host ip_address_of_router eq 22
interface gigabitEthernet 0/0
ip access-group 100 in

However, other end users are needed to access the router via ping utility:

On the router:

ip access-list extended 100
permit icmp network_id wildcard_mask host router_id echo


4.2) ACL config on Sw1:

interface vlan 1
ip access-group 100 in
exit
access-list 100 permit tcp host ip host switch_ip eq 22	
access-list 100 permit icmp network_id wildcard_mask host switch_id echo

SECTION 4

4.1) NAT config on R1:

Determine the inbound(linked with local) and outbound interfaces(linked with internet router)

Open R1:

interface gigabitethernet0/0
ip nat inside
interface gigabitethernet0/1
ip nat outside
exit
ip route 0.0.0.0 0.0.0.0 120.120.120.2
ping 8.8.8.8
ip nat inside source list 10 interface gigabitethernet0/1

after pinging from pc to 8.8.8.8 , check with show ip nat translations on R1
